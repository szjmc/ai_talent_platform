## 七、常见问题（都是本次真实踩到的）

| 现象 | 根因 | 处理 |
| --- | --- | --- |
| `ImportError: cannot import name 'StrEnum' from 'enum'` | 用了 3.10 解释器 | 换 3.13 环境（本文档第一节） |
| `ModuleNotFoundError: No module named 'greenlet'` | SQLAlchemy async 必需依赖未装 | `pip install greenlet` |
| `ModuleNotFoundError: No module named 'app'` | 未设置 `PYTHONPATH` | 命令前加 `PYTHONPATH=.` |
| `RuntimeError: Event loop is closed`（集成测试） | 公共 conftest 的引擎跨事件循环复用 | 集成测试已在 `tests/integration/conftest.py` 自建 `NullPool` 引擎（文件头有说明） |
| `'C:\...\python.exe': No such file` | Git Bash 不解析 `../` 相对路径里的空格/中文 | 用绝对路径调用解释器 |
| 启动日志 `已实现 3 个模块` | 旧版本硬编码文案 | 本轮已改为按真实清单输出（MATCH-010） |
| `角色不存在：['admin','super_admin']` | 首次建库未初始化角色 | 先跑 `scripts/create_admin.py`（内部会补齐全部 `RoleEnum`） |
