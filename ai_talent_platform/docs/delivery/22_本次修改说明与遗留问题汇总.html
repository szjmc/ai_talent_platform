二、遇到的问题和怎么解决的

1requirements.txt 编码坑（UTF-16）

伙伴的文件是 UTF-16 编码，我直接按 UTF-8 追加导致接缝全是乱码。解决：放弃追加，用程序检测 BOM、从伙伴原版整个重建为 UTF-8。

2键名复制即损坏（NL2SQL_PGSQL_USER → NL2SQL_RNKGO_IIGU）

通过对话输出通道复制这个键名会变成乱码。解决：不再手抄，用正则从 settings.py 里程序化提取正确键名反写。

3本地环境缺包 + pip 装包被代理挡

合并后的代码需要 sqlglot、chromadb，本地 venv 没有；默认源被代理挡住装不上。解决：换清华镜像 -i https://pypi.tuna.tsinghua.edu.cn/simple 安装成功。

4"合并是否引入新问题"怎么验证？

用 git worktree 对照测试法：临时开一个 worktree 跑伙伴的纯净分支，和合并后的代码在相同环境下各跑一遍全量非集成测试。结果：两边失败集合完全一致（17 个，全是对方分支就有的老问题，多为环境依赖：PG 关闭、chromadb、env 敏感等）。结论：合并零引入新失败。
