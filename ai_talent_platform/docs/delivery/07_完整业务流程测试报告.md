## 一、被测业务链路（L4）

```
岗位 1「后端开发工程师」
  → ① JD 原文解析（草稿）
  → ② HR 确认画像（生成 v4，生效）
  → ③ 召回候选池（5 人）
  → ④ 四态硬条件判定
  → ⑤ 四维打分 + UNKNOWN 降权
  → ⑥ 排序 + top_k
  → ⑦ 证据构建
  → ⑧ 解释生成
  → ⑨ 证据校验（剔除编造/矛盾结论）
  → ⑩ 落库（批次 + 明细 + 统计 + 淘汰原因）
  → ⑪ 回读（列表 / 最新批次 / 人才历史 / 单条解释）
```

```
                 'required_skills：缺少必备技能：mysql（命中 2/3）']
```

**业务正确性核验（人工复算）**

| 项 | 复算过程 | 结论 |
| --- | --- | --- |
| 分母对不对 | `candidates=5` = 3 保留 + 2 淘汰 | ✅ 没有静默丢弃候选人 |
| 王强为何没被淘汰 | 三项硬条件分别是 UNKNOWN / NEEDS_REVIEW / UNKNOWN，**没有一项是 FAIL** | ✅ 只有 FAIL 淘汰 |
| 王强分数怎么来的 | `0×0.4 + 55×0.3 + 25×0.2 + 70×0.1 = 28.5`，存在 UNKNOWN → 降权 15% → `28.5×0.85 = 24.225 ≈ 24.22` | ✅ 0~100 且可复算 |
| 张伟 vs 陈晨 | 两人前三维度都是 100，`quality` 95 vs 80，权重 0.1 → 差 1.5 分 | ✅ 综合分由加权决定，非满足项计数 |
| 赵敏为何三条原因 | 学历/年限/技能都不满足，逐条列全（不是只报第一条） | ✅ 淘汰可解释 |
| 李娜为何只报技能 | 学历硕士≥本科、年限 4≥3 均满足，只有技能不满足 | ✅ 未误报 |
