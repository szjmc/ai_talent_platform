## 一、数据存储层（多数据库混合架构）

### MySQL（业务主库，mysql+aiomysql 全异步）

- [x] 业务主数据 ORM：27 张表全部建模（users/roles/user_roles/organizations + 岗位 / 人才 / 简历 / 文件 / 测评 / 培训 / 匹配 / 知识库 / 会话 / 审计 + 人才邀约 / 笔试会话 [Agent组 2026-11-06 追加]）

## 二、服务接口层

- [x] 基于 FastAPI 全异步框架搭建，应用工厂 + lifespan 生命周期（启动自检、优雅关闭释放连接池）
- [x] 统一接口规范（/api/v1 前缀，Router → Service → Repository 严格分层，依赖方向自上而下）
- [x] 统一返回格式（code / message / data / trace_id 四段式）
- [x] 统一异常处理（16 类业务异常 + 全局处理器，业务码与 HTTP 状态码同步）
- [x] 统一权限拦截（JWT 双令牌 + RBAC 依赖注入：require_permission / require_roles / require_superuser）
- [x] 数据范围控制（全部 / 本部门 / 本部门及下级 / 仅本人，4 级 DataScope 纯函数校验）
- [x] 统一日志（trace_id 全链路追踪、访问日志、耗时统计、慢请求告警、滚动日志文件）
- [x] 接口限流（进程内滑动窗口，300 次/分钟/IP，超限返回 429 统一响应）
- [x] 安全响应头（nosniff / X-Frame-Options / Referrer-Policy 等）+ CORS 跨域配置
- [x] 自动生成 API 文档（Swagger /docs + ReDoc /redoc，支持 Authorize 在线调试）
- [x] 健康检查（/health 存活探针；/health/ready 就绪探针，返回各库状态、失败原因与修复建议）
- [x] 统一分页（PageParams / PageResult，页码/页大小/总数/总页数）
- [x] 所有数据操作通过 ORM 对象关系映射实现（SQLAlchemy 2.0 全异步，业务代码禁止裸 SQL）
- [x] BaseRepository 通用 CRUD（17 个方法：分页、筛选白名单、模糊搜索、排序白名单、软删除、唯一冲突守卫）
- [x] 显式事务控制（SAVEPOINT 嵌套事务 + MySQL 死锁/锁超时自动重试，指数退避）
- [x] 未实现模块占位路由（统一返回 501 + 负责人提示，Swagger 可见，前端不 404）
- [ ] 熔断（未实现）
- [ ] 第三方系统对接（未实现）
