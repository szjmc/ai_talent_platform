# MVP 分析指标口径

- dim_talent_wide：每个talent_id一行；人数是count(*)。学历和潜力等级可分组；缺失值须保留为未知，不擅自补全。
- fact_talent_snapshot：按snapshot_month、organization_id、education、age_group分层快照。部门总计使用organization_id>0且education=''、age_group=''；学历分析固定age_group=''且education非空；年龄分析固定education=''且age_group非空。禁止把汇总行和细分行重复求和。
- 上月以分析库current_date所属自然月为基准。确定性接口的月度人才存量同比使用上一年同月、环比使用上个月；按用户指定月份范围查询，不以服务器当天擅自替换目标月份。缺本期/基期或基期为0时rate=null、status=无法计算，真实本期0与缺期严格区分。季度/年度聚合口径暂未扩展，不把每月存量相加当季度人数。
- 部门归属：dim_organization.org_id对应业务部门ID，path只含祖先，不含自身，例如部门3在根部门1下时path='/1/'。
- 测评：total_score为0—100；avg(total_score)为测评记录平均分，不是按人才去重后的平均分。level按源系统记录分组，不重新计算等级。
- 培训：用户确认以“已有学习记录”为分母、“通过考核”为完成标准，同时明确“暂不扩表，暂停完成率实现”。MySQL源learning_records.passed表达是否通过，但fact_training_track没有passed及源记录ID；本轮不新增字段/迁移，不以学习事件条数或progress/status替代通过考核。study_minutes求和仅表述为记录分钟合计，是否增量由源ETL确认。
- 匹配：公式已确认：最新批次中score达到阈值的匹配记录数÷该批全部匹配记录数；默认建议阈值70，支持用户给出的60/70/80/85/90等阈值选择。按MatchingRepository现有说明，按岗位取最大matched_at记录所属batch_id，建议接口要求position_id，不擅自改成全局最新批次。match_avg_score只是平均匹配分，不能代替匹配率。用户已选择先由匹配/数据组提供公开数据接口，Vanna随后接入；当前不修改对方模块、不直扫MySQL、不扩表、不返回假值。对接字段及异常规则见接口文档匹配率待接入契约。
- 技能：skill_tags为数组；每人可有多个技能。确定性技能分布先展开数组、去除空标签、按人才ID与规范技能去重，再统计人数；一个人可进入多个技能，分类合计不能当作人才总数。无有效技能的人员在确定性接口保留“未知”分类。技能筛选支持all/any，与分类计数统一去除标签首尾空格；all对请求标签去重后要求全部包含，不能因请求或源数组重复标签而重复计数。同类多值OR、跨字段AND。自然语言语料增加逐项展开与学历/年限/技能组合示例，须重新导入记忆后生效；不能把整个数组组合分组冒充单技能分布。
- 行为：event_type/page可按事件记录计数；duration_ms可计算已记录事件的平均时长，不能推断全体用户。
- 用户已明确本次不做人才流动/流失趋势，相关同比环比也不涉及；不新增占位接口。骨干、继任者、达标率仍缺正式事件/阈值定义，不生成假口径。
- 查询仅使用授权分析库六表；所有输出必须继承当前查询权限。

## 确定性分析接口补充（2026-11-04）

- 学历、年龄、组织分布以fact_talent_snapshot为依据；可指定month（当月1日），省略时选择授权组织范围内最新月份，并在响应标出实际月份。只选一个汇总层级，不把organization_id=0总计与明细部门相加。学历与年龄联合交叉口径未确认，不通过拼接两组单维汇总实现假交叉。
- 技能以dim_talent_wide当前宽表为依据，不伪装成历史技能快照；宽表缺可靠组织ID/年龄字段时拒绝对应筛选。测评可以通过talent_id子查询关联学历、技能、潜力和工作年限，不做会扩大记录行数的多对多JOIN。
- 测评统计record_count为记录数、scored_count为非NULL得分记录数、talent_count为人才去重数，平均值仅按非NULL得分的测评记录计算。时间条件使用带时区的start_at/end_at，左闭右开。
- 月度趋势talent_total是每月人数存量，不能把两期存量之差叫新增人数/流失人数；缺期返回null及missing=true，真实快照的0保留为0。
- /analytics/compare比较用户明确指定的两个快照；差额=本期-基期，change_rate=差额/基期（未乘100）。缺任一分类或基期为0时不计算比例，返回null、rate_status=无法计算。此接口与/trend?comparison=mom/yoy/both互补，后者自动寻找自然月基期，不要求基期位于展示区间内。
- 培训完成率按用户要求暂停；岗位匹配率已明确公式和默认阈值，等待匹配/数据组数据接口就绪后实施。不返回占位0，不从平均匹配分或学习事件数推导替代指标。
